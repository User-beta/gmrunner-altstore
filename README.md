# gmrunner AltStore source

AltStore source for **gmrunner**, a clean-room GameMaker Studio 1.4 runner for iOS.

To add it, go to AltStore > Sources > **+** and enter:

```
https://raw.githubusercontent.com/User-beta/gmrunner-altstore/main/apps.json
```

The app contains no game data. After installing, open it once, then copy your own `data.win` (and the game's `.ogg` files) into **On My iPhone > gmrunner** with the Files app.

Builds are published as [releases](https://github.com/User-beta/gmrunner-altstore/releases).
